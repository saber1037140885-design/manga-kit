# 验收标准（白夜 2026-11-09 定）

**四条不能崩：手、脸、光、姿势。** 任何一条不过，这张就不发——不是"下次注意"，是这一张废掉重跑。

## 一、手

- [ ] 五指数量对，不融合、不多指
- [ ] 关节方向对（拇指在正确一侧，手指不反折）
- [ ] **手在做事**，不是藏着或虚化
- [ ] 手上没有莫名其妙多出来的东西（戒指、发光、第六指）

**不过就**：正向 `detailed hands`，负向 `mutated hands, extra digits, fused fingers, missing fingers`；姿势换成明确的动作词（`gripping the bedsheet`），不要写"手放在身上"。

## 二、脸

- [ ] 五官位置对，双眼同高、同大小、看同一个方向
- [ ] 嘴不露牙（除非就是要张嘴），不流口水
- [ ] **表情只有一个状态**，不是僵住的半垂眼
- [ ] 发际线、刘海、侧切都在（公主切的三件套不能缺）
- [ ] 脸没被头发或手挡掉超过一半

**不过就**：负向用 `face` 组（`teeth showing, drooling, asymmetrical eyes, distorted face`）；表情词减到一个；咬唇类词和 teeth 类词不能同时出现。

## 三、光

- [ ] 光只有一个来源、一个方向
- [ ] 该亮的地方确实亮（B 光下脸和膝盖内侧要亮）
- [ ] 暗部没有脏（不是死黑，是有层次的暗）
- [ ] 没有跑色调（B 光不许发暖黄、不许发蓝紫）
- [ ] 影子对得上光源位置

**不过就**：B 光线检查负向有没有 `warm light, orange light, lamp, night`；厚涂线检查有没有 `warm yellow tint, oily skin`；两条线不能混。

## 四、姿势

- [ ] 骨架逻辑成立（关节能弯的方向）
- [ ] 重心在支撑上（不会自己悬空）
- [ ] 身体没有多出来的部分，没有粘连
- [ ] 姿势和场景对得上（不会在床上做站姿动作）
- [ ] **不是"摆拍感"**——手、塌陷、压痕至少有一处说明她在用力

**不过就**：加 `from behind / from above` 等明确机位；把复杂的扭身拆成简单姿势；服装和姿势分开写。
