# 姿势库

**一张图只给一个姿势，手只做一件事。** 两个姿势叠在一起，模型会画成一个扭曲的四不像。

这个库是按「手部安全」排的序，不是按好看排序——2026-11-11 验过：手一旦被要求做细节动作（抓、捏、撑、扣），整只手在 1168×1704 里只有约 80px，指缝没地方画，必崩。所以每行都标了手在哪。

## 一、安全区（手闲着、藏着、出画——随便抽）

| 名 | 正向写法 | 手在哪 / 备注 |
|---|---|---|
| 跪坐 | `kneeling, sitting on heels, seiza` | 手放在大腿上，最稳的一张 |
| 仰卧 | `lying on back, arms at sides` | 手在身侧，衣服会自然塌下来 |
| 抱腿 | `sitting, knees up, hugging own legs` | 手臂环住小腿，看不见手指 |
| 侧卧撑头 | `lying on side, propped up on elbow` | 一只手撑头，手掌被头发挡住 |
| 趴卧回看 | `lying on stomach, looking back at viewer` | 手肘撑着，手掌压在床单里 |
| 靠墙 | `leaning against wall, one knee bent` | 一只手贴墙，手指贴平面 |
| 站立 | `standing, hands behind back` | 手在身后，看不见 |
| 坐床边 | `sitting on edge of bed, legs crossed` | 手撑在床沿，手掌朝下 |
| 坐椅 | `sitting on chair, legs crossed` | 手放膝上 |
| 蹲 | `squatting, knees together` | 手抱膝，藏在腿后 |

## 二、半安全区（手有事做，但动作简单——可以抽，抽崩了重抽）

| 名 | 正向写法 | 风险 |
|---|---|---|
| 撩头发 | `hand in own hair, brushing hair aside` | 手指插进发丝，偶尔粘连但可看 |
| 拉肩带 | `pulling down own strap, one hand on shoulder` | 手指只碰布，不碰皮肤 |
| 捂嘴 | `hand over own mouth` | 手掌挡脸，看不见指节 |
| 抱胸 | `arms crossed under chest, arms folded` | 手臂交叠，手指藏进臂弯 |
| 撑下巴 | `hand on own cheek, resting chin on hand` | 侧脸压手背 |
| 抓床单 | `gripping bedsheet, clenched hand` | 手指抓布，褶皱会吃掉手指细节 |
| 按胸口 | `one hand on own chest` | 手掌贴平，不抓 |

## 三、危险区（手在做细节动作——单抽必崩，留给局部重绘）

| 名 | 正向写法 | 为什么危险 |
|---|---|---|
| 四肢撑床 | `all fours` | 四只手掌着地，全在画面里 |
| 分腿坐 | `spread legs, sitting` | 两只手都要撑住重心 |
| 解扣子 | `unbuttoning shirt, fingers on button` | 指尖捏东西，最难的形状 |
| 抓窗帘 | `hand on curtain, pulling curtain` | 实测崩成一团 |
| 扶地起身 | `getting up, hand on floor` | 五指张开压地 |
| 交握 | `hands clasped together, fingers intertwined` | 十指相扣，指缝全暴露 |

> 危险区不是不能用：先用安全区出一张干净底图，再**裁出单手 → 短边放大到 768 → 重采样 → 贴回**。整套流程在 `notes\出图\手部修复.md`。

## 四、姿势跟镜头的关系

- `full body` / `cowboy shot`：全身和膝上，手必然进画——优先选安全区。
- `upper body` / `portrait`：手多半在画外，可以破一次规矩用半安全区。
- `from above`（俯拍）：跪姿、仰卧最好看，头会变小、肩会变宽。
- `from below`（仰拍）：站姿、靠墙，腿会拉长，但容易画出畸形小腿。
- `dutch angle`（歪镜头）：只在想表达失衡时用，一张里有它就够了。

## 写作注意

1. **一个姿势 + 一个动作**：`lying on back, arms at sides` 是完整的一句，别再追加 `spread legs`。
2. **别写 `pose` 这个词**，它对模型没有信息量。
3. 姿势定了，**衣服的失效方式要跟着改**：跪着写肩带滑落，躺着写衣摆被压到腰上。
4. `knees together` 比 `knees apart` 稳定——后者常把骨盆画歪。
